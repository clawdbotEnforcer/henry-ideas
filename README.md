# Henry Ideas Repository

Autonomous idea generation and repository analysis by Henry AI.

## Structure

```
ideas/
├── apps/           # New app concepts
├── improvements/   # Enhancements to existing repos
├── bugs-found/     # Issues discovered during analysis
└── test-cases/     # Test coverage suggestions

daily-summaries/    # Daily reports of generated ideas
templates/          # Idea templates
```

## Idea Sources

- **Repo Analysis**: Continuous scanning of GitHub repos for patterns, gaps, and opportunities
- **Otter Transcripts**: Ideas captured from voice conversations
- **Autonomous Generation**: Novel concepts based on observed patterns

Check `daily-summaries/` for the latest report.
